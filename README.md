# Smart-ATM-System-in-C

A simple console-based ATM simulation built in C language.

### 💳 Features
- PIN Authentication (PIN: 1234)
- Check Balance
- Deposit Money
- Withdraw Money
- Secure Exit

### 🚀 How to Run
1. Compile the file: `gcc atm.c -o atm`
2. Run the program: `./atm` or `atm.exe`

### 🛠️ Technology Used
- C Language
- Logic: Loops, Switch Case, Conditional Statements
